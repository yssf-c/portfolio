# Ternpost portfolio assets

Sourced from the local Ternpost project (https://ternpost.vercel.app), November 2026:

- `app/{view}-{theme}-{mode}.webp`: the website's app screens (`website/src/assets/app/`), captured from the current build with sample mail. Four views (inbox, commands, search, reply), seven themes (paper, classic, graphite, fjord, sage, plum, ember), light and dark. 1920 × 1200. The theme names, descriptions and colours in `components/projects/ternpost-experience.tsx` match the website's showcase.
- `icon.svg`: the brand's master app icon (`brand/ternpost-icon.svg`).

The Archivo display face in `app/fonts/archivo/` is the website's self-hosted variable file, under the SIL Open Font License (`LICENSE.txt` beside it).
